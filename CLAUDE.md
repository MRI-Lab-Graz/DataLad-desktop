# Repo rules

- Always use the `ponytail` and `superpowers` skills when working in this repo.
- Always use TDD (red, green, refactor) for every new feature and function: write the failing test first, then the implementation. Tests run with `npm test` (Node built-in runner).
- Before every merge (PR into `main`), run the `ponytail:ponytail-audit` skill over the changes and handle or consciously decline its findings.
