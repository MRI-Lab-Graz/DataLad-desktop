# Diff View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show what changed in a file: a **Show changes** toggle under each changed file on Home, and **Compare with now** on a save in Tools → History, both rendering one shared diff view.

**Architecture:** The adapter runs read-only `git diff` (always with `--no-ext-diff --no-textconv`) and returns the patch as text plus metadata. A pure renderer module (`diff-view.js`) parses the patch and renders escaped HTML, including cell highlighting for TSV/CSV. Two new IPC handlers expose it; `app.js` wires the Home toggle and the History compare list to one `loadDiffInto` function.

**Tech Stack:** Electron renderer (plain ES modules), Node built-in test runner (`npm test`), e2e via `env -u ELECTRON_RUN_AS_NODE npm run test:e2e`.

**Spec:** `docs/superpowers/specs/2026-10-12-diffs-design.md`

## Global Constraints

- Zero new npm dependencies.
- TDD for every change: failing test first (source-text tests count, repo pattern).
- Every new `git diff` invocation passes `--no-ext-diff --no-textconv --no-color --no-renames`, puts the pathspec after `--`, and gets file names from `-z` output.
- File content is never put into `innerHTML` unescaped: all text goes through `escapeHtml` (`src/gui/renderer/escape-html.js`).
- Diff cap: first 500 lines by default; "Show the rest" requests up to 20 000 (`DIFF_MAX_LINES`).
- No new write path, no new IPC beyond `adapter:getFileDiff` and `adapter:listChangesSince`, both behind `requireAuthorizedRoot`.
- Vocabulary: "save" and "version", never "checkpoint" or "commit" in UI text.
- Commit trailer on every commit: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
- Before merge into `main`, run `ponytail:ponytail-audit` over the changes (CLAUDE.md). The maintainer merges PRs on GitHub; Claude cannot.
- Ruling carried into this plan: the adapter returns the diff as a **patch string** (starting at the first `@@`), not parsed lines; the renderer parses it. This keeps the main process thin and puts the parser next to its tests. The spec's `lines` field becomes `patch`.

## Review Focus

- An untracked file that is binary (NUL bytes), huge, or not valid UTF-8: shown as "Data file changed" or capped, never a crash or a hang (Task 2).
- A locked annexed file (a symlink into `.git/annex/objects`, key contains `-s<bytes>--`): shown as a data file with sizes, never as link-target text (Task 2).
- Hostile input over IPC: a path with `..`, an absolute path, a path starting with `-`, a bad hash, a non-string: refused before any git runs (Task 2, Task 4).
- The file watcher re-renders the Home list while a diff is open: the diff stays open and refreshes, it does not collapse or show stale content (Task 5).
- A TSV/CSV pair of lines with different cell counts, or a quoted field containing the separator: falls back to the plain line diff, never a wrong highlight (Task 1).
- A file deleted in the working tree: shown as all-removed lines (Task 2); a file with a space or umlaut in its name works end to end (Task 7).

```js
// Pure rendering of a file diff (from the adapter's getFileDiff) as escaped HTML.
// TSV/CSV files get their changed cells highlighted. No DOM access; same pattern as project-health-chips.js.
import { escapeHtml } from './escape-html.js'

export const DIFF_DEFAULT_LINES = 500
export const DIFF_MAX_LINES = 20000

/** @param {string} patch unified diff starting at its first "@@" line */
export function parseUnifiedDiff(patch) {
  const lines = []
  for (const line of patch.split(/\r?\n/)) {
    if (line.startsWith('@@')) {
      lines.push({ type: 'hunk', text: line })
    } else if (line.startsWith('+')) {
      lines.push({ type: 'add', text: line.slice(1) })
    } else if (line.startsWith('-')) {
      lines.push({ type: 'del', text: line.slice(1) })
    } else if (line.startsWith(' ')) {
      lines.push({ type: 'context', text: line.slice(1) })
    }
    // "\ No newline at end of file" and the empty tail after the last newline are dropped.
  }
  return lines
}

export function separatorFor(path) {
  const extension = /\.([^./\\]+)$/.exec(path)?.[1]?.toLowerCase()
  if (extension === 'tsv' || extension === 'tab') {
    return '\t'
  }
  return extension === 'csv' ? ',' : null
}

// ponytail: a plain split; fields with quotes (which may hold the separator) fall back to the line diff.
export function cellChanges(oldLine, newLine, separator) {
  if (oldLine.includes('"') || newLine.includes('"')) {
    return null
  }
  const before = oldLine.split(separator)
  const after = newLine.split(separator)
  if (before.length !== after.length) {
    return null
  }
  return {
    old: before.map((text, index) => ({ text, changed: text !== after[index] })),
    new: after.map((text, index) => ({ text, changed: text !== before[index] }))
  }
}

export function formatBytes(bytes) {
  const units = ['B', 'KB', 'MB', 'GB', 'TB']
  let value = bytes
  let unit = 0
  while (value >= 1024 && unit < units.length - 1) {
    value /= 1024
    unit += 1
  }
  return unit === 0 ? `${value} B` : `${value.toFixed(1)} ${units[unit]}`
}

function rowHtml(type, mark, content) {
  return `<div class="diff-line diff-${type}"><span class="diff-mark">${mark}</span>${content}</div>`
}

function cellsHtml(cells, separator) {
  return cells
    .map((cell) => (cell.changed ? `<span class="diff-cell-changed">${escapeHtml(cell.text)}</span>` : escapeHtml(cell.text)))
    .join(escapeHtml(separator))
}

function renderRows(lines, separator) {
  const rows = []
  for (let index = 0; index < lines.length; ) {
    const line = lines[index]
    if (line.type === 'hunk') {
      rows.push(rowHtml('hunk', '', escapeHtml(line.text)))
      index += 1
    } else if (line.type === 'context') {
      rows.push(rowHtml('context', ' ', escapeHtml(line.text)))
      index += 1
    } else {
      // A run of removed lines followed by added lines: pair them by position for cell highlighting.
      const removed = []
      const added = []
      while (lines[index]?.type === 'del') {
        removed.push(lines[index].text)
        index += 1
      }
      while (lines[index]?.type === 'add') {
        added.push(lines[index].text)
        index += 1
      }
      const paired = separator ? removed.map((text, i) => (i < added.length ? cellChanges(text, added[i], separator) : null)) : []
      removed.forEach((text, i) => {
        rows.push(rowHtml('del', '-', paired[i] ? cellsHtml(paired[i].old, separator) : escapeHtml(text)))
      })
      added.forEach((text, i) => {
        rows.push(rowHtml('add', '+', paired[i] ? cellsHtml(paired[i].new, separator) : escapeHtml(text)))
      })
    }
  }
  return rows.join('')
}

const STATUS_WORD = { added: 'added', deleted: 'deleted', modified: 'changed' }

/**
 * @param {{ kind: string, status?: string, patch?: string, totalLines?: number, truncated?: boolean, oldSize?: number|null, newSize?: number|null }} diff
 * @param {{ path: string, requestedMax: number }} options
 */
export function renderDiffHtml(diff, { path, requestedMax }) {
  if (diff.kind === 'unchanged') {
    return '<p class="hint-inline">No changes.</p>'
  }

  if (diff.kind === 'binary') {
    const sizes = [diff.oldSize, diff.newSize].every((size) => size === null || size === undefined)
      ? ''
      : ` (${diff.oldSize == null ? 'new' : formatBytes(diff.oldSize)} → ${diff.newSize == null ? 'removed' : formatBytes(diff.newSize)})`
    return `<p class="hint-inline">Data file ${STATUS_WORD[diff.status] ?? 'changed'} (not shown as text)${sizes}.</p>`
  }

  const lines = parseUnifiedDiff(diff.patch ?? '')
  let footer = ''
  if (diff.truncated) {
    const shown = lines.length
    footer = requestedMax < DIFF_MAX_LINES
      ? `<p class="hint-inline">Showing ${shown} of ${diff.totalLines} lines. ` +
        '<button type="button" class="button button-ghost button-inline diff-more-button">Show the rest</button></p>'
      : `<p class="hint-inline">Showing ${shown} of ${diff.totalLines} lines. The rest is not shown.</p>`
  }
  return `<div class="diff" role="group" aria-label="Changes in ${escapeHtml(path)}">${renderRows(lines, separatorFor(path))}</div>${footer}`
}
```

export const DIFF_DEFAULT_LINES = 500
export const DIFF_MAX_LINES = 20_000
// A diff must never run a program named by repository content (diff.<driver>.command, textconv, GIT_EXTERNAL_DIFF).
export const DIFF_SAFE_FLAGS = ['--no-ext-diff', '--no-textconv', '--no-color', '--no-renames']

const ANNEX_KEY_SIZE = /-s(\d+)--/

    value.length > 0 &&
    !value.includes('\0') &&

```js
  async getFileDiff(projectPath, request = {}) {
    // Hostile input is refused before any git process starts.
    const { path, against } = request
    if (!isSafeRelativePath(path)) {
      throw new Error(`Invalid file path: ${String(path)}`)
    }
    if (against !== 'HEAD' && !(typeof against === 'string' && COMMIT_HASH_PATTERN.test(against))) {
      throw new Error(`Invalid commit hash format: ${String(against)}`)
    }
    await this.#ensureGitProject(projectPath)
    const requested = Number.parseInt(request.maxLines, 10)
    const maxLines = Math.min(Math.max(Number.isFinite(requested) && requested > 0 ? requested : DIFF_DEFAULT_LINES, 1), DIFF_MAX_LINES)

    if (against === 'HEAD') {
      const others = await this.runner.run('git', ['-C', projectPath, 'ls-files', '--others', '--exclude-standard', '-z', '--', path])
      if (!others.failed && (others.stdout ?? '').length > 0) {
        return this.#diffUntrackedFile(projectPath, path, maxLines)
      }
    }

    const result = await this.runner.run('git', ['-C', projectPath, 'diff', against, ...DIFF_SAFE_FLAGS, '-U3', '--', path])
    if (result.failed && !(result.stdout ?? '')) {
      if (against === 'HEAD' && /bad revision|unknown revision|ambiguous argument/i.test(result.stderr ?? '')) {
        throw new Error('There is nothing to compare with yet: this project has no saves yet.')
      }
      throw new Error(`Could not compare ${path}: ${(result.stderr ?? '').trim() || 'unknown error'}`)
    }
    return this.#shapeDiff(projectPath, against, path, result.stdout ?? '', maxLines)
  }

  async #shapeDiff(projectPath, against, path, output, maxLines) {
    if (output.trim() === '') {
      return { kind: 'unchanged', status: 'modified', patch: '', totalLines: 0, truncated: false, oldSize: null, newSize: null }
    }
    const lines = output.split(/\r?\n/)
    const firstHunk = lines.findIndex((line) => line.startsWith('@@'))
    const header = (firstHunk === -1 ? lines : lines.slice(0, firstHunk)).join('\n')
    const status = /^new file mode/m.test(header) ? 'added' : /^deleted file mode/m.test(header) ? 'deleted' : 'modified'
    const body = firstHunk === -1 ? [] : lines.slice(firstHunk)
    while (body.length > 0 && body.at(-1) === '') {
      body.pop()
    }

    // A locked annexed file is a symlink (mode 120000) whose target holds the key, and the key holds the size.
    if (/\b120000\b/.test(header)) {
      const sizeOf = (marker) => {
        const line = body.find((candidate) => candidate.startsWith(marker))
        const match = line ? ANNEX_KEY_SIZE.exec(line) : null
        return match ? Number(match[1]) : null
      }
      return { kind: 'binary', status, patch: '', totalLines: 0, truncated: false, oldSize: sizeOf('-'), newSize: sizeOf('+') }
    }

    if (/^Binary files .* differ$/m.test(header) || /^GIT binary patch$/m.test(header) || firstHunk === -1) {
      return {
        kind: 'binary',
        status,
        patch: '',
        totalLines: 0,
        truncated: false,
        oldSize: status === 'added' ? null : await this.#blobSize(projectPath, against, path),
        newSize: status === 'deleted' ? null : await this.#worktreeSize(projectPath, path)
      }
    }

    return {
      kind: 'text',
      status,
      patch: body.slice(0, maxLines).join('\n'),
      totalLines: body.length,
      truncated: body.length > maxLines,
      oldSize: null,
      newSize: null
    }
  }

  async #blobSize(projectPath, rev, path) {
    const result = await this.runner.run('git', ['-C', projectPath, 'cat-file', '-s', `${rev}:${path}`])
    const size = Number.parseInt((result.stdout ?? '').trim(), 10)
    return result.failed || !Number.isFinite(size) ? null : size
  }

  async #worktreeSize(projectPath, path) {
    const info = await lstat(join(projectPath, path)).catch(() => null)
    return info?.isFile() ? info.size : null
  }

  // An untracked file has no saved version: show its start as all-added lines. Never reads outside the
  // project (a symlink, or a path through a symlinked folder, is reported as a data file instead).
  async #diffUntrackedFile(projectPath, path, maxLines) {
    const data = (size) => ({ kind: 'binary', status: 'added', patch: '', totalLines: 0, truncated: false, oldSize: null, newSize: size })
    const full = join(projectPath, path)
    const info = await lstat(full).catch(() => null)
    if (!info) {
      return { kind: 'unchanged', status: 'added', patch: '', totalLines: 0, truncated: false, oldSize: null, newSize: null }
    }
    const [realRoot, realFile] = await Promise.all([realpath(projectPath).catch(() => null), realpath(full).catch(() => null)])
    if (!info.isFile() || !realRoot || !realFile || !realFile.startsWith(realRoot + sep)) {
      return data(info.isFile() ? info.size : null)
    }

    const handle = await open(realFile, 'r')
    let bytes
    try {
      const buffer = Buffer.alloc(Math.min(info.size, UNTRACKED_READ_LIMIT))
      const { bytesRead } = await handle.read(buffer, 0, buffer.length, 0)
      bytes = buffer.subarray(0, bytesRead)
    } finally {
      await handle.close()
    }
    if (bytes.subarray(0, 8000).includes(0)) {
      return data(info.size)
    }

    const fileLines = bytes.toString('utf8').split(/\r?\n/)
    if (fileLines.at(-1) === '') {
      fileLines.pop()
    }
    const body = [`@@ -0,0 +1,${fileLines.length} @@`, ...fileLines.map((line) => `+${line}`)]
    return {
      kind: 'text',
      status: 'added',
      patch: body.slice(0, maxLines).join('\n'),
      totalLines: body.length,
      truncated: body.length > maxLines || info.size > UNTRACKED_READ_LIMIT,
      oldSize: null,
      newSize: null
    }
  }
```

async function loadDiffInto(container, { projectPath, path, against, maxLines = DIFF_DEFAULT_LINES }) {
  container.dataset.diffAgainst = against
  container.hidden = false
  container.innerHTML = loadingPanelHtml('Loading changes…')
  try {

    container.innerHTML = renderDiffHtml(diff, { path, requestedMax: maxLines })

function homeDiffContainer(path) {
  return [...elements.changedFilesOutput.querySelectorAll('[data-diff-container]')].find((node) => node.dataset.diffContainer === path)

async function refreshOpenDiffs() {
  const projectPath = readProjectPath()

      continue

    state.openDiffs.set(path, await loadDiffInto(container, { projectPath, path, against: 'HEAD' }))
